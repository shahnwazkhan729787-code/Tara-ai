# 🌸 Tara AI — Intelligent Voice & Chat Assistant

**Tara AI** is an AI-powered voice and chat assistant developed by **Shahnwaz**.

It provides real-time AI conversations with voice interaction, chat history, and support for multiple AI models.

## ✨ Features

- 🤖 AI Chat with Google Gemini
- 🧠 Support for Grok (xAI)
- 🔥 Support for OpenAI
- 🎤 Voice input and voice responses
- 📞 Real-time voice call mode
- 💬 Real-time streaming responses
- 📝 Markdown rendering
- 🕘 Chat history
- 🎨 Modern and responsive user interface
- 🌐 Deployed on Vercel
